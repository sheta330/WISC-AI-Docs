Layer 3: Service Decorators

🔑 Key Concept: Decorator Pattern

Each decorator wraps the layer below, adding new behavior without modifying the Core

Decorator Function Layer
PersonaEnhancedQueryService Formats responses in Egyptian persona style 3 (Outermost)
SecureSmartQueryService Cross-tenant validation and security 2
SmartQueryServiceV2 Core logic (Frozen 🔒) 1
// Registration in Program.cs (Lines 311-332) builder.Services.AddScoped<ISmartQueryServiceV2>(sp => { var innerService = sp.GetRequiredService<SmartQueryServiceV2>(); var tenantValidator = sp.GetRequiredService<TenantScopedValidator>(); // Layer 2: Security var securityWrapped = new SecureSmartQueryService( innerService, tenantValidator, ...); // Layer 3: Persona return new PersonaEnhancedQueryService( securityWrapped, ...); });

🔄 Complete Flow (End-to-End)

User: "هاتلي فلوس أحمد" ("Show Ahmed's balance") ↓ [UnifiedSmartQueryController.QueryAsync] → Extract JWT → Tenant/User IDs → Validate ModelState → Resolve Session (Existing/New) ↓ [PersonaEnhancedQueryService.ExecuteAsync] → Call inner service → Format response in Arabic persona ↓ [SecureSmartQueryService.ExecuteAsync] → Validate tenant isolation → Check cross-tenant safety ↓ [SmartQueryServiceV2.ExecuteAsync] 🔒 → Build metadata context → Add smart tags [T:Table][C:Column] → Call RagOrchestrator ↓ [RagOrchestrator.ProcessQuery] → IntentClassifier: Egyptian/English detection → QueryDecomposer: Break complex queries → CommandGenerator: Generate SQL via LLM → SecureQueryExecutor: Execute with tenant params ↓ [OllamaProvider.GenerateAsync] → POST /api/generate (local) → Return generated SQL ↓ Response: { Data, SQL, Metadata, Persona-Formatted Message }

🎯 Design Principles

1. Additive-Only Architecture

Core logic is Frozen - Development happens via Decorators from outside

2. Strict Offline Mode

No Cloud APIs - Ollama local only for security and privacy

3. Tenant Isolation

Every query validated against tenant - no data leak between tenants

4. Egyptian Arabic First

System understands Egyptian dialect as priority - not machine translation
