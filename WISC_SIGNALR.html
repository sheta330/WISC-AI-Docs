🎯 Overview

The Thought Stream provides real-time visibility into AI processing steps via SignalR WebSocket. This enables interactive UIs that show users exactly what the system is doing behind the scenes.

🔗
WebSocket Connection
// SignalR Hub Endpoint URL: /wisc-ai-live-stream-v1 Protocol: WebSocket (SignalR) Auth: JWT Bearer Token required // Connection Flow 1. Client connects with JWT 2. Server validates tenant from token 3. Client joins tenant-specific group 4. Server broadcasts thought messages

📨 Thought Message Schema

📋
ThoughtMessage Structure
{ "correlationId": "a1b2c3d4e5f67890", // Links to API response "step": "IntentClassification", // Current processing step "status": "InProgress", // Pending | InProgress | Complete | Failed "message": "Analyzing query intent...", // Human-readable description "progress": "25%", // Optional progress indicator "timestamp": "2024-01-15T10:30:15.123Z", // ISO 8601 timestamp "metadata": { // Step-specific data "detectedLanguage": "EgyptianArabic", "intent": "CustomerBalanceInquiry" } }

🔄 Processing Steps Timeline

The following steps are broadcast in chronological order during query processing:

1. QueryReceived

Query received and validated. Starting AI pipeline.

⏱️ ~10ms
2. IntentClassification

Analyzing natural language intent using Egyptian Arabic classifier.

🤖 AI Processing
3. EntityResolution

Finding entities in query: Customer names, dates, amounts.

🔍 Pattern Matching
4. ContextBuilding

Loading database schema and building metadata context.

📊 Schema Loading
5. SqlGeneration

Generating SQL query via Ollama LLM.

📝 LLM Generation
6. SecurityValidation

Validating tenant isolation and security constraints.

🔒 Security Check
7. QueryExecution

Executing SQL against tenant database.

⚡ Database
8. ResultFormatting

Formatting results with Arabic persona.

🎭 Persona Layer
9. Complete

Query complete. Results returned via API.

✅ Done

💻 Client Implementation Examples

🔶 Angular Client

// Install: npm install @microsoft/signalr import * as signalR from '@microsoft/signalr'; const connection = new signalR.HubConnectionBuilder() .withUrl('/wisc-ai-live-stream-v1', { accessTokenFactory: () => localStorage.getItem('jwt_token') }) .build(); // Listen for thought messages connection.on('ReceiveThought', (message) => { console.log(`Step: ${message.step}`); console.log(`Status: ${message.message}`); // Update UI progress bar updateProgress(message.step, message.progress); }); await connection.start();

🔷 Flutter/Dart Client

// Install: signalr_netcore package import 'package:signalr_netcore/signalr_client.dart'; final connection = HubConnectionBuilder() .withUrl( 'wss://api.wisc-erp.com/wisc-ai-live-stream-v1', HttpConnectionOptions( accessTokenFactory: () async => getJwtToken(), ), ) .build(); // Listen for thought stream connection.on('ReceiveThought', (args) { final message = args![0] as Map<String, dynamic>; print('Step: ${message['step']}'); print('Message: ${message['message']}'); // Update UI setState(() { currentStep = message['step']; statusMessage = message['message']; }); }); await connection.start();

React/Vue Component Example

// React Hook for Thought Stream function useThoughtStream(correlationId) { const [thoughts, setThoughts] = useState([]); useEffect(() => { const connection = new signalR.HubConnectionBuilder() .withUrl('/wisc-ai-live-stream-v1') .build(); connection.on('ReceiveThought', (msg) => { if (msg.correlationId === correlationId) { setThoughts(prev => [...prev, msg]); } }); connection.start(); return () => connection.stop(); }, [correlationId]); return thoughts; } // Usage in component function QueryProgress({ correlationId }) { const thoughts = useThoughtStream(correlationId); return ( <div className="thought-stream"> {thoughts.map(t => ( <div key={t.timestamp} className={t.step}> <span className="step-name">{t.step}</span> <span className="message">{t.message}</span> {t.progress && <ProgressBar value={t.progress} />} </div> ))} </div> ); }
